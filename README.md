⚡ AutoLab Calculator

AutoLab Calculator adalah aplikasi berbasis web untuk membantu pengguna melakukan konversi besaran listrik dan menghitung rumus dasar kelistrikan dengan lebih mudah dan praktis.

✨ Fitur Utama

* 🔌 Konversi Besaran Listrik — Konversi arus, tegangan, resistansi, frekuensi, daya, energi, dan kapasitansi.
* 🧮 Kalkulator Rumus Listrik — Perhitungan menggunakan Hukum Ohm, rumus daya, dan energi listrik.
* 📋 Riwayat Perhitungan — Menyimpan riwayat perhitungan selama sesi aplikasi.
* 🌐 Berbasis Web — Dapat digunakan melalui browser.

🛠️ Teknologi yang Digunakan

* Python
* Flask
* HTML
* CSS

🚀 Cara Menjalankan Aplikasi

1. Clone repositori ini:

git clone https://github.com/meisyakinata889-oss/AutoLab-Calculator.git

2. Masuk ke folder proyek:

cd AutoLab-Calculator

3. Instal dependensi:

pip install -r requirements.txt

4. Jalankan aplikasi:

python app.py

5. Buka browser dan akses alamat lokal yang ditampilkan Flask, biasanya:
    http://127.0.0.1:5000

🎯 Tujuan Proyek

AutoLab Calculator dikembangkan untuk mempermudah proses perhitungan dan konversi besaran listrik serta membantu pengguna memahami penerapan rumus dasar kelistrikan dalam pembelajaran.

👩‍💻 Pengembang

Dikembangkan sebagai proyek pembelajaran dan penerapan pemrograman web menggunakan Python dan Flask.
